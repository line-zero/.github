# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Use GitHub's private vulnerability reporting feature for the affected repository when it is available. If private reporting is not available, contact LineZero through the contact information published at https://linezero.io.

Include enough detail to reproduce or understand the issue, but do not include unnecessary customer data, credentials, secrets, or other sensitive information.

We will acknowledge legitimate reports and coordinate remediation and disclosure as appropriate.
